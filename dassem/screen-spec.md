# 화면 명세 (screen-spec)

기준: `reference/dasseum-prototype-standalone.html`. 기기 기준 폭 375pt, 좌우 마진 20, 배경 #F7FAF8.
DS = 사용할 공통 컴포넌트(`theme/components.tsx`).

## 0. 스플래시
- 목적: 앱 실행 시 브랜드 시작 화면
- 구성: 마스코트 smile 180 중앙 → 로고 '다씀.'(Wanted Sans 800, 40/48, #1E8C7E, 마스코트 아래 12) → 슬로건 "있는 걸 먼저, 끝까지 다 쓰는 습관"(14/20, Label/Alternative, 로고 아래 8). 하단 여백 40으로 시각 중심을 약간 위로.
- 동작: 1.8초 후 홈으로 교체(replace), 250ms 페이드. 뒤로가기로 돌아오지 않음.
- RN: `expo-splash-screen`의 네이티브 스플래시가 끝난 뒤 이 화면을 JS로 보여 주는 구조 권장.

## 1. 홈 (하단 탭)
- 헤더 56: 텍스트 로고 '다씀'(22, 800) · 알림 아이콘(bell, 미확인 시 6px 빨간 점)
- 인사: "확인이 필요한 제품이\n2개 있어요"(22/30 bold) + "있는 걸 먼저, 끝까지 다 쓰는 습관"(14, Alternative) · 우측 마스코트 smile 140
- 빠른 실행 2열(gap 10, minHeight 112, padding 16): 좌 [제품 등록] 화이트 카드(camera, "찍어서 내 물품에 추가") → 3(등록 모드) · 우 [구매 전 확인] 민트 카드(search, "사기 전에 먼저 확인해요") → 2
- 먼저 써야 할 제품: 섹션 헤더 + [전체보기] → 먼저 써야 할 제품 목록. 가로 스크롤 카드 148폭(썸네일 124, 제품명 2줄, 추천 사유 민트 배지) → 6
- 사용기한 임박: 화이트 카드 안 리스트(썸네일 44, 이름, "카테고리 · 개봉/미개봉", D-day 배지) → 6
- 소비 관리: 크림 카드 "이번 달 소비 관리 / 다씀 N개 · 구매 보류 N회" + chevron → 8(구매 보류 탭)
- 알림 아이콘: 미구현(토스트)

## 2. 구매 전 확인 (하단 탭)
- 제목 "구매 전 확인"(24) · 설명 "사기 전에 내 물품에 있는지 확인해요"
- (마스코트 없음, 상단 여백 20 유지)
- SearchInput → [확인하기](solid, 빈 값이면 비활성) · [사진으로 확인하기](outlined, camera 아이콘)
- 최근 확인: history 아이콘 + 검색어 + 날짜(MM.DD), 행 탭 → 해당 검색어로 4, 우측 X로 개별 삭제. 최대 5개, 최신순. 비었을 때 "최근 확인한 제품이 없어요"
- 키보드 검색(enter)도 확인하기와 동일

## 3. 사진으로 확인 / 제품 등록 촬영
- 배경 #1B1C1E, 흰 텍스트. 상단 X(닫기) · 제목(구매 전 확인: "사진으로 확인" / 등록: "제품 등록")
- 가이드 프레임 248×300, 모서리 표시 3px 흰색 radius 16, 안쪽 카메라 미리보기 영역
- "제품 이름이 잘 보이게 찍어주세요"
- 하단: 앨범(48, 반투명) · 셔터(72 흰 원, 링) · 빈 자리
- 동작: 구매 전 확인 → 4(mode=photo) / 등록 → 기존 Expo 목업(비타민D 자동 입력) 유지. 프로토타입은 홈 복귀 + 토스트
- RN: `expo-camera` 사용 예정. 권한 거부 시 PRD 9장 처리

## 4. AI 확인 중
- 중앙: 마스코트 search 160 → "내 물품과 비교하고 있어요"(20 bold) → "‘{검색어}’과 같거나 비슷한 제품을 찾는 중이에요" / 사진이면 "촬영한 사진과…"
- 하단 [취소](outlined) → 이전 화면
- 목업: 1.7초 후 5로 replace. 실제: API 응답 시 이동, 10초 초과 시 오류 상태(open-questions)
- 스피너 없음(디자인 결정). 진행감 부족 여부는 사용자 테스트 관찰 항목

## 5. AI 확인 결과
- TopBar "확인 결과" + 뒤로
- 질의 요약 바(fillAlternative, radius 10): search/camera 아이콘 + "‘{q}’ 확인 결과" 또는 "촬영한 사진으로 확인했어요"
- 상태 배지 → 제목(24) → 설명(15, Alternative)

| 판정 | 배지 | 제목 | 설명 | 버튼 |
|---|---|---|---|---|
| same | warn "동일 제품 있음" | 이미 가지고 있어요 | 내 물품에 같은 제품이 1개 있어요. | [구매 보류] / [그래도 구매할게요] |
| similar | mint "유사 제품 있음" | 비슷한 제품이 있어요 | 같은 브랜드의 다른 용량 제품이에요. | [구매 보류] / [그래도 구매할게요] |
| none | ok "보유 제품 없음" | 가지고 있는 제품이 없어요 | 내 물품에서 ‘{q}’과 같거나 비슷한 제품을 찾지 못했어요. | [확인 완료] / [다시 확인하기] |

- 보유 제품 카드(same/similar): 썸네일 72 · 브랜드·카테고리 · 제품명 · (similar) 차이 설명 · 구분선 · 개봉일/사용기한+D-day · [보유 제품 상세 보기](outlined md) → 6
- InfoBanner: "AI 확인 결과는 참고용이에요. 실제 제품을 확인해 주세요." + 영양제·의약품이면 "영양제·의약품의 효능이나 대체 가능 여부는 안내하지 않아요."
- 구매 보류 → 기록 저장 + 토스트 "구매를 미뤘어요. 있는 것부터 써요" → 7
- 그래도 구매할게요 / 확인 완료 → 2로 리셋(검색어 비움, 기록 없음)
- '결과가 달라요' 버튼은 v2에서 제거됨
- 기존 Expo 목업 유지: '안약' → 인공눈물 similar

## 6. 보유 제품 상세
- TopBar(뒤로, 더보기 → 미구현)
- 4:3 이미지(크림 플레이스홀더) → 카테고리 배지 → 브랜드 → 제품명(22)

## 하단 탭
홈(home) · 구매 전 확인(search) · 내 물품(storage) · 설정(setting). 활성 = Label/Normal + Fill 아이콘, 비활성 = rgba(55,56,60,.45). 라벨 11/14 600. 배경 화이트 + 상단 헤어라인. 설정은 기존 임시 화면 유지.
