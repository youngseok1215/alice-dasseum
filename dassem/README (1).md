# 로고

현재 로고는 이미지 파일이 아니라 **텍스트 로고타입**입니다. 공식 로고 파일(SVG)이 생기면 이 폴더에 넣어 주세요.

| 사용처 | 텍스트 | 글꼴 | 크기 | 색 |
|---|---|---|---|---|
| 스플래시 | 다씀. | Wanted Sans ExtraBold(800) | 40 / 48, 자간 -0.04em | #1E8C7E (확정 필요) |
| 홈 헤더 | 다씀 | Wanted Sans ExtraBold(800) | 22, 자간 -0.03em | #171719 |

- Wanted Sans: https://github.com/wanteddev/wanted-sans (OFL). `expo-font`로 로드
- 글꼴이 없으면 Pretendard ExtraBold로 대체 가능
